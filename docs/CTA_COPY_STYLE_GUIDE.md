# CTA Copy Style Guide

This guide defines the standard call-to-action (CTA) wording for BrightNest Academy marketing pages.

## Primary Goal
Use clear, action-oriented labels that are consistent across pages, widgets, and mobile bars.

## Approved CTA Labels
- Book a Demo
- Talk to an Advisor
- WhatsApp Us
- Call Now
- Get Directions
- Explore Course
- View All Courses

## Usage Rules
- Use sentence case for all CTA labels.
- Use title-style capitalization as written in the approved labels above.
- Keep CTA text short (2-4 words where possible).
- Use "Book a Demo" as the main conversion CTA.
- Use "Talk to an Advisor" for contact-intent actions that go to the contact page.
- Use "WhatsApp Us" for all WhatsApp chat actions.
- Use "Call Now" for direct phone actions.

## Labels To Avoid
Replace these older variants wherever found:
- Book Demo
- Book Free Demo
- Book FREE Demo
- Book Free Demo Class
- Book a Free Demo Class
- Contact Us (for button CTAs on marketing pages)
- Chat on WhatsApp (for button CTAs)
- WhatsApp Admissions

## Scope
Apply this guide to:
- Static marketing pages in src/main/resources/static
- Shared components and widgets in src/main/resources/static/js
- Mobile sticky CTA bars and popups

## Notes
- Body copy may mention "free demo class" where context requires detail.
- CTA button text should remain standardized to the approved labels.
